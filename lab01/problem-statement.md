# Problem statement · ITC Club Hub (v0.1, 2026-10-21)

## Problem
The problem of club updates being scattered across too many different apps affects students trying to join activities and leaders trying to run them; the impact of which is people missing out on events, dead group chats, and hours spent on annoying paperwork.
A successful solution would put everything into one simple dashboard to handle sign-ups, event promotion, and room bookings smoothly.

## Vision
For busy students and club organizers who are tired of chasing down event details or losing track of members, ITC Club Hub is a dedicated campus activity portal that makes it easy to see exactly what is happening on campus.
Unlike messy WhatsApp groups and chaotic email threads, our product keeps all club info organized, searchable, and tied directly to the institute calendar.

## Today's workaround
Right now, running a club is a bit of a mess. Organizers track their members on random Google Sheets, spam everyone on Discord or WhatsApp for announcements, print out paper flyers to tape on campus walls, and play endless phone-tag or email-tennis with the administration just to reserve a room for a meeting.

## Scope
- Built in C++ this semester:
  * The core backend logic to store member profiles, club lists, and event times.
  * A text-based terminal menu (CLI) for admins to manage user accounts and system data.
  * Saving and loading data directly to local text files (.txt or .csv) so info isn't lost when the app closes.
  * A basic login menu to check usernames and verify if someone is a student or an admin.
- Modelled only (web and mobile):
  * Figma mockups of the main student feed showing upcoming campus events.
  * Mobile UI layouts showing how push notifications would look for last-minute event changes.
  * Wireframes for a club leader dashboard showing basic member growth stats.
- Out of scope:
  * Setting up real online credit card processing or payment links for club membership fees.
  * Deploying a live website to a public server like AWS or Azure.
  * Publishing an actual mobile application onto the Apple App Store or Google Play Store.
